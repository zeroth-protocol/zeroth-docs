# Zeroth Website Design Governance

## Source precedence

1. **Claude Design handoff** — canonical website UI source of truth.
2. **Zeroth Brand & Corporate ID Standards v1.0** — locked identity constraints.
3. **Figma** — conformant production-design reconstruction.
4. **This codebase** — implementation. Code must not reinterpret the approved design language.

## Non-negotiables

- `#BEFF8B` Zeroth Abundance is the signature accent and remains limited to verified / active / settled states and primary CTAs.
- Origin surface is `#050706`.
- Geist for display, Inter for interface/body, Geist Mono for evidentiary data.
- Flat hairline surfaces; no decorative card shadows or glows.
- Motion doctrine: `UNRESOLVED → STRUCTURED → VERIFIED → FINAL`.
- No spring or bounce animation.
- Reduced motion resolves immediately.
- Simulations must be labelled `PROTOCOL SIMULATION — ILLUSTRATIVE`.
- Network status remains `RESEARCH / PRE-PRODUCTION` until explicitly ratified otherwise.

## Review rule

Implementation changes that materially affect composition, typography, spacing, interaction, motion or responsive behavior require visual comparison against the canonical Figma reconstruction and the Claude Design handoff before merge.
